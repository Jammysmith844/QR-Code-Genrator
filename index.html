How it works

This tool encodes your text into a QR code directly in your browser using a small JavaScript library that implements the QR specification. The code is drawn onto a canvas element, and you can download it as a PNG. No network requests are made, and no data ever leaves your device.

  1. Enter the text or URL you want to encode.
  2. Pick a size, error correction level, and margin.
  3. Click Download PNG to save the image, or Copy image to paste it elsewhere.

QR codes are stored as plain black-and-white pixel grids — no tracking, no redirects, no expiration. The code you generate today will scan exactly the same tomorrow.

Common uses

  • Links: Put a QR code on a poster, business card, or slide to open a URL quickly.
  • Wi-Fi sharing: Encode a Wi-Fi network using the standard format WIFI:T:WPA;S:MyNetwork;P:MyPassword;; so guests can connect without typing.
  • Contact details: Use a vCard string to share a phone number, email, and organization.
  • Plain text: Serial numbers, short notes, or instructions that need to be scanned offline.
  • Event check-in: Give each attendee a unique code to scan at the door.

Good to know

  • Keep it short. QR codes with fewer characters are easier to scan. Long URLs create dense patterns that older phones may struggle to read.
  • Use a margin. The standard 4-module quiet zone around the code helps scanners lock on. Removing it can cause failures.
  • Higher error correction (Q or H) is useful if the code will be printed on a curved surface, a fabric, or a background that isn't pure white.
  • Test before printing. Scan the downloaded PNG with your phone before sending it to a print shop.
  • Contrast matters. Dark pattern on a light background scans reliably. Inverted colors (white on black) work on many phones but not all.

Frequently asked questions

Do the QR codes expire?

No. The code is a direct encoding of your text. It doesn't point to a redirect service, so it will keep working as long as the text it contains is still valid.

Is there a length limit?

The tool caps input at 1,000 characters. In practice, QR codes work best under about 300 characters — long inputs produce a very dense pattern that's harder to scan.

Can I use the PNG for commercial printing?

Yes. The images are generated entirely on your device and carry no watermark, license, or attribution requirement.

Why does my QR code look so dense?

Density comes from the amount of text and the error correction level. Reduce the text, lower the ECC level, or both, to get a sparser code that scans more easily.

Will the QR code work with any scanner?

Yes. The output is a standard QR code that any compliant scanner — iPhone camera, Android camera, and dedicated apps — can read.

Does this page store my data?

No. Nothing is sent to a server, no cookies are set, and nothing is logged. Once you close the tab, everything is gone.

Limitations

  • The tool generates QR codes only. It does not scan them — use your phone's camera or a dedicated reader app for that.
  • Colored QR codes, embedded logos, and design frames are not supported. The output is a plain black-and-white PNG.
  • Very long inputs (over ~500 characters) may produce codes that some older scanners cannot read reliably.
  • SVG export is not offered in this version — only PNG.
